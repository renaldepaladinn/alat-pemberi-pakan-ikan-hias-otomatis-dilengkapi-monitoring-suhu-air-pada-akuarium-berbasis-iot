## Alat Pemberi Pakan Ikan Hias Otomatis Dilengkapi Monitoring Suhu Air Pada Akuarium Berbasis IoT
Proyek sistem pemberi pakan ikan hias otomatis berbasis ESP32 yang dilengkapi pemantauan suhu air akuarium melalui platform Blynk. Sistem menggunakan sensor DS18B20 untuk membaca suhu air dan motor servo untuk mengatur pemberian pakan berdasarkan jadwal yang telah ditentukan.

## Fitur
  • Pemantauan suhu air akuarium menggunakan sensor DS18B20.
  • Monitoring suhu secara real-time melalui platform Blynk.
  •	Indikator kondisi suhu air: panas, hangat, normal, atau dingin.
  •	Pemberian pakan ikan otomatis sesuai jadwal.
  •	Pengaturan waktu pemberian pakan menggunakan fitur RTC pada Blynk.

## Teknologi
Mikrokontroler: ESP32
Pemrograman: Arduino framework
